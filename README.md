# Autonomous 🤖

Autonomous is a chatbot we built for our first hackathon. It's made with plain HTML, Tailwind CSS, and vanilla JavaScript — no frameworks, no build tools, nothing fancy. Just the basics we knew at the time, and a lot of late-night Googling.

We didn't know much when we started. But we kept working on it, fixing things, breaking things, and fixing them again. This is what came out of it.

# 📖 What is this?
Autonomous is a small chatbot that answers questions about GNIOT GIPS — courses, fees, hostel, placements, campus, contact info — everything a new student or parent might want to know.

It runs entirely in the browser. No backend, no server setup. Just one HTML file you open and start chatting with.

Under the hood it uses Google's Gemini API to generate replies, and a small knowledge base we wrote ourselves with all the GNIOT GIPS details. It can also do math, tell you the time, and look up general facts from Wikipedia if you ask it something outside the college.

We made this during our first hackathon. It wasn't perfect, but it was ours.

# 🎯 How it actually works
You type a message. JavaScript checks what you said against some predefined patterns and keywords. Then it picks a response and shows it on screen.

It's not smart. It doesn't learn. It's just a bunch of if statements and string matching. But it works, and we were proud of it.
