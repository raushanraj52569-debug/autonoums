# Autonomous 🤖

Autonomous is a chatbot we built for our first hackathon. It's made with plain HTML, CSS, and vanilla JavaScript — no frameworks, no libraries, nothing fancy. Just the basics we knew at the time, and a lot of late-night Googling.

We didn't know much when we started. But we kept working on it, fixing things, breaking things, and fixing them again. This is what came out of it.

# 📖 What is this?
Autonomous is a simple chatbot that runs in your browser. You type something, it replies. That's it. No backend, no server, no AI model behind it just JavaScript doing its thing.

We made this during our first hackathon. It wasn't perfect, but it was ours.

# 🛠️ What we used
## What	Why?

> HTML5	 - To build the structure

> Tailwind css  -	To make it look decent

> Vanilla JavaScript - To make it actually work
That's it. Nothing else.

# 🎯 How it actually works
You type a message. JavaScript checks what you said against some predefined patterns and keywords. Then it picks a response and shows it on screen.

It's not smart. It doesn't learn. It's just a bunch of if statements and string matching. But it works, and we were proud of it.
